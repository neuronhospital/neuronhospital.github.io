Category preferences are stored on this browser. When an event reaches the open website through an available NEURON integration, the browser can show a system notification if permission and that event category are enabled.

Permission is requested only after you select the button. Browser notifications are not the same as Android FCM: this website currently has no Web Push subscription or service-worker push receiver, so it cannot receive events while closed or reliably in the background.
